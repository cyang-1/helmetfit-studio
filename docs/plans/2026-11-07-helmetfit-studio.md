# 量身造盔 · 完整开发与验收计划

**目标**　让创作者从一张图片或同一件头盔的多视图出发，生成外形，输入头围或实测尺寸，加工成可试戴、可装配并能在 P1S 上实际切片的工程。用户也可以从自己的 GLB、OBJ、STL 开始。执行顺序按功能依赖，下面每一步均由真实产物验收。

| 步骤 | 开发内容 | 完成依据 |
|---|---|---|
| 1. 工作台 | 本机启动入口、作品列表、项目持久化、上传限制、任务状态与断点恢复 | 关闭页面或重启服务后，能找到同一个项目，调整参数和下载已有文件 |
| 2. Lux3D 外形 | 官方区域网关、短期上传凭证、单图与多图、有凭证的创建/查询、GLB 下载校验。记录任务号并控制重试 | 分别以原创单图和多图得到真实任务号与 GLB，浏览器中能旋转查看。密钥错误时显示可操作的返回原因，修复密钥后重试。已知成功与接口契约测试分开记载 |
| 3. 制造坐标 | 将 GLB 节点及变换烘焙到统一制造空间，导入原有 OBJ/STL，提供外形预览和正面姿态校正 | 外形方向、尺寸和对齐操作与 Blender 输出吻合；保留可查看的 GLB |
| 4. 佩戴尺寸 | 从头围标定眉线截面；头宽、头长、头高可覆盖估算。构造自建头模与含余量、耳部和戴入空间的刀具 | 同输入的头模预览及真实布尔使用相同几何；输入尺寸冲突可见。关联试戴环、头部尺寸与修订 |
| 5. 制造处理 | 挖内腔、可调贯通眼窗、剖面、由成品截取试戴环。检查网格、抽样壁厚、入口和眼部。超限分件、适宜位置加定位销 | 有效输入产出成品与环；不合格输入标明原因和修正入口。小件单盘和超限分件分别实测 |
| 6. P1S 出盘 | 加载官方预设并展开继承与模板，为每个部件排盘、加支撑、切片；校验工程内嵌机型、热床范围、启停代码、材料及模型刀路 | Bambu Studio 能打开可编辑工程；每盘有正层数、用料、实际模型壁挤出和切片时长。ZIP 包含试环、全部盘及装配记录。应用只生成打印工程 |
| 7. 交付 | 新用户入口、原创本地样件、失败修正、可打印制作记录、清洁打包与回归命令 | 解压后的应用从浏览器完成上传、定尺、切片、下载和重新打开。不分发密钥、旧版商业头模及私人模型 |

## 验收层次

- **软件实现**：对整条可控流程做接口、浏览器与真实几何/切片验证。源文件、测试和启动方式见项目根的 STUDIO.md。
- **云端成功回执**：由有效 Aholo 开放平台 Key、正确账号区域与可用额度产生。记录实际输入、taskId、GLB 和后续本机加工结果。没有真实回执时明示其状态，本地原创示例独立标注来源。
- **实物验收**：操作者用与工程一致的 P1S、0.4 mm 喷嘴、PLA 与纹理 PEI 板先打环，再决定整盔。记录宽长误差、松紧、入口、装配和摘戴。切片数字只代表软件估算。

## 提交交付物

当前表单的四项必填为完整 Demo 或真实运行视频、报告书、实际使用的生态合作设备/技术、应用赛道。建议选择与 3D 打印应用对应的下拉项，报告展示同一原创设计的原图、生成 GLB、佩戴剖面、试环、各盘和实物反馈。可选项为源码与 X 发布链接（话题 #Manycorehackathon）。没有经过实测的步骤在报告中标明验证边界。

## 选型与范围

Three.js 用于浏览器预览，Blender 4.5 负责几何，Bambu Studio 原生 CLI 负责打印工程。Python 3.11 标准库提供本机服务、SQLite 与异步任务，减少便携包安装负担。Aholo Lux3D API 直接生成图片项目的核心 3D 资产。项目无需安装 MCP 客户端，开发者可使用官方 MCP 复核云任务。首发配置为 P1S。公开网站、多人账号、云端切片和自动启动实机不在本次本机应用的交付范围内。
